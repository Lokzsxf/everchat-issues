# Everchat: bugs and ideas

Bug reports and ideas for [Everchat](https://www.curseforge.com/wow/addons/everchat), the chat overhaul for World of Warcraft: Forever.

- [Report a bug](https://github.com/Lokzsxf/everchat-issues/issues/new?template=bug.yml)
- [Suggest an idea](https://github.com/Lokzsxf/everchat-issues/issues/new?template=idea.yml)

Have a look at the [open issues](https://github.com/Lokzsxf/everchat-issues/issues) first. If yours is already there, a thumbs up on it helps me see what matters most.

If the game shows a Lua error, its text is the most useful part of a report. BugSack keeps errors so you can copy them, or type `/console scriptErrors 1` in the chat to see them as they happen.

No GitHub account? A comment on the [CurseForge page](https://www.curseforge.com/wow/addons/everchat) works too.
